# Audits

Dated audit and incident write-ups (speed, voice latency, proactive replies,
scheduling incidents) live here on the development machine only.

They are built from real use of the assistant, so they quote real messages and
a real calendar. They are kept out of the public repository for that reason.
Code comments that cite `docs/audits/<date>-<topic>.md` refer to those local
files. The regression tests each incident produced are public, next to the code
they cover (for example `plugin/orion-control/src/*incident*.test.ts`).
